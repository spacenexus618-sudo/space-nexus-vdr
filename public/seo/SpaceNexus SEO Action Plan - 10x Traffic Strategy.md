## Phase 1: Technical SEO & Indexing Mastery

**1. Fix the 2 "Crawled – Currently Not Indexed" Pages**
Google has crawled 2 pages but refused to index them. Identify these URLs in GSC → Coverage → "Crawled – currently not indexed". Audit each page for thin content, duplicate content, or missing canonical tags. Enrich the content with at least 800–1,000 words of unique value, then request indexing via the URL Inspection tool in GSC.

**2. Expand the XML Sitemap and Re-Submit to GSC**
Currently only a handful of pages are tracked. Generate a comprehensive sitemap covering all solution pages, blog posts, feature pages, and landing pages. Submit via GSC → Sitemaps and confirm Google processes it without errors. This ensures all new content is discovered rapidly.

**3. Increase Crawl Budget – Fix Orphaned Pages**
Pages like `/features/qa` (28 impressions, pos 4.14) and `/demo` (3 impressions, pos 6) are barely internally linked. Audit the full internal link structure using Screaming Frog or Sitebulb. Ensure every page is reachable within 3 clicks from the homepage and has at least 3 internal links pointing to it.

**4. Audit and Strengthen `robots.txt` and Canonical Tags**
Review `robots.txt` to confirm no important pages are accidentally blocked. Audit all pages for self-referencing canonical tags. Ensure the `/solutions/secure-document-sharing-for-legal` page (163 impressions, pos 65) has a valid canonical pointing to itself and is not inadvertently excluded from indexing.

**5. Optimize Core Web Vitals for Desktop and Mobile**
Desktop gets all 11 clicks; mobile has 68 impressions but 0 clicks (pos 27.71). Run the site through PageSpeed Insights. Target LCP < 2.5s and CLS < 0.1 for all key landing pages. Prioritize mobile performance — a faster mobile experience can unlock the 68 currently unconverted mobile impressions.
